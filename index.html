처음 한 번만 Windows와 공유기를 준비하면 같은 Wi-Fi가 아니어도 휴대폰에서 PC를 깨울 수 있습니다.

01 · WINDOWS

PC WOL 설정

WakeQR를 실행하고 ‘Windows WOL 설정’을 누릅니다. BIOS/UEFI의 Wake on LAN은 PC 제조사 설정에서 한 번 확인하세요.

02 · ROUTER + QR

공유기 자동 설정

‘공유기 자동 설정 + 통합 QR’을 누릅니다. 성공하면 외부 깨우기까지 QR 하나에 담기며, 미지원 공유기는 앱에서 관리자 화면과 정확한 수동 설정값을 안내합니다.

03 · SCAN & WAKE

QR 한 번 스캔

WakeMyPC 앱에서 QR을 한 번 읽으면 등록이 끝납니다. 이후 Wi-Fi나 셀룰러 어디서든 깨우기 버튼을 누르세요.

실행 전 확인

WakeQR는 공유기 비밀번호를 요구하거나 저장하지 않습니다. 자동 설정은 공유기가 제공하는 UPnP/NAT-PMP 기능만 사용합니다.
  • ✓Windows 10 또는 Windows 11, 64비트 PC
  • ✓BIOS/UEFI에서 Wake on LAN 또는 PCIe Wake 활성화
  • ✓가능하면 Wi-Fi 대신 유선 LAN 사용
  • ✓등록할 때 PC가 공유기에 연결되어 있고 공유기의 UPnP/NAT-PMP가 활성화
  • ✓자동 설정이 안 되면 WakeQR가 보여주는 IP·MAC·포트 값을 공유기에 한 번 입력
RUN ON WINDOWS

다운로드한 파일
실행 방법

ZIP 압축을 푼 뒤 WakeQR.exe를 실행하세요. 앱 자체는 관리자 권한이 필요하지 않으며, ‘Windows WOL 설정’을 누를 때만 관리자 권한을 요청합니다.

1. WakeQR-v1.1.1-windows-x64.zip 다운로드
2. ZIP 파일 우클릭 → 모두 압축 풀기
3. WakeQR.exe 실행

SmartScreen이 표시되면
“추가 정보” → “실행”을 선택하세요.
