폰으로 트랙패드

같은 Wi-Fi에 연결된 아이폰이나 아이패드를 Mac과 Windows PC의 무선 트랙패드로 사용합니다.

App Store에서 보기 컴퓨터 연결 앱
Trackpad Remote

주요 기능

주변 컴퓨터 연결
무료 연결 앱을 실행한 컴퓨터를 같은 네트워크에서 찾습니다. Windows PC는 IP 주소를 입력해 연결할 수도 있습니다.
멀티터치 제스처
탭, 드래그, 스크롤, 핀치 확대와 화면 전환을 지원합니다. Mac에서는 Mission Control, Windows에서는 작업 보기를 열 수 있습니다.
빠른 입력과 감도 조절
숫자, 복사, 붙여넣기, Enter를 빠른 버튼으로 입력합니다. 포인터와 스크롤 감도는 사용하는 기기에 맞춰 조절합니다.
