문서는 기기 안에서 처리합니다

한글뷰 개발자는 앱을 통해 사용자의 문서 내용, 파일명, 사용 기록 또는 개인정보를 수집하거나 서버로 전송하지 않습니다. 회원가입, 광고, 추적 및 자체 분석 도구를 사용하지 않습니다.

기기에 저장되는 정보

‘최근 문서 기록’이 켜져 있으면 다시 열 수 있도록 선택한 문서의 로컬 사본과 파일명·형식·크기·최근 열어본 시간을 앱 저장 공간에 보관합니다. 화면 테마와 최근 문서 기록 설정도 기기에 저장합니다. 개발자는 이 정보에 접근하지 않습니다.

설정에서 ‘최근 문서 기록’을 끄면 앱에 보관한 문서 사본과 기록을 삭제합니다. 앱을 삭제하면 앱 저장 공간의 데이터가 제거됩니다. 파일 앱 등 사용자가 별도로 저장한 원본이나 내보낸 사본은 해당 위치에서 직접 관리해야 합니다.

파일 선택과 공유

문서 선택은 iOS 파일 선택 화면을 사용합니다. 사용자가 iCloud Drive나 다른 파일 제공자를 선택하면 해당 서비스의 정책이 적용됩니다. 사용자가 저장·공유를 선택한 문서 사본은 iOS 공유 화면에서 직접 선택한 앱 또는 저장 위치로 전달됩니다. 개발자 서버로 전달되지 않습니다.

문의와 외부 서비스

고객지원 웹사이트는 GitHub Pages에서 제공하며, 방문 시 GitHub가 운영상 필요한 접속 정보를 처리할 수 있습니다. 지원 요청을 GitHub에 남기면 사용자가 작성한 내용이 해당 서비스에 저장·공개됩니다. 앱의 로컬 문서 처리와는 별개이며, 개인정보나 문서 원본을 공개 문의에 포함하지 마세요.
